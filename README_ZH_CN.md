# Agent OS：一套可插拔的 Agent 记忆系统

这个仓库是一套轻量、与平台无关的 **AI Agent 记忆系统**。它把 Agent 的长期记忆保存为 Git 仓库里的纯 Markdown 文件，让记忆的生命周期长过任何一个模型、产品或会话。

## 为什么是"记忆"

模型会越来越聪明，但真正让一个助手变成*你的*助手，靠的不是智能。上下文窗口一重置、产品一换后端，模型就把你忘了。真正会复利、且没有任何厂商能白送的，是**关于你的记忆**——你的偏好、你的标准、你的项目、你的做事方式。这个项目把这份记忆变成一个独立资产：你拥有它、保存它，并把它插到下一个 Agent 上。

## 核心公式

> Agent = 智能 + 行动能力 + 记忆 + 主动性

智能与行动能力越来越同质化，只有记忆这一项会持续增长。这个仓库就是那份记忆——刻意极简、纯文本、与所有模型和平台解耦。

## 设计要点

- **三层砍成两层。** OpenClaw 的记忆分为内层（身份与规则）、中层（长期知识）、表层（日常琐事）。因为现代 Agent 产品可以低成本地新开一个对话，表层被砍掉。剩下的是只读的内核 + 可写的长期记忆。
- **记忆按环境隔离。** 每条记忆都带一个 `env` 标签（`global`、`local`、`cloud`），因此同一个仓库既能驱动本地 IDE 里的 Agent，也能驱动无状态的云端沙盒里的 Agent，且行为正确。
- **通过 `/learn` 自进化。** Agent 把一次会话中的收获抽象成一个新的记忆文件，剥离项目细节后写回——本地写磁盘，云端则提交并推送。

## 仓库结构

```text
仓库/
├── README.md                   # 本文件——面向新人的门面
├── WAKEUP.md                   # 核心宣言——每次唤醒先读
├── .memory/                    # 大脑（全局知识）
│   ├── 00_kernel/              # [只读] 角色设定、记忆格式、能力发现
│   ├── preferences/            # [读/写] 用户偏好与风格
│   ├── principles/             # [读/写] 行动准则
│   ├── entities/               # [读/写] 系统级概念
│   └── corrections/            # [读/写] 错误日志与修复
└── lab/                        # 身体（行动空间）
    ├── _toolkit/               # [云端镜像] 脱敏后的日常工具
    └── <temporary_projects>/   # [读/写] 临时项目目录
```

## 让它变成你的

Fork 或 clone 这个仓库，把 `.memory/` 的内容换成你自己的。结构不变，记忆成你的。然后唤醒它——任何能读写 Git 仓库的 Agent 都能使用它。
