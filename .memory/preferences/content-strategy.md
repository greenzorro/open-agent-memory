# Victor42 内容战略与平台原则

## 1. 个人品牌优先

- 平台只是渠道，真正需要长期积累的是代表 Victor42 思维方式的个人品牌。
- 个人品牌核心不是某个垂直领域，而是理性、深度、系统化、效率至上和严谨求证的思维方式。
- 内容主题可以分散，但共同内核应稳定；读者追随的是这种思考方式，而不只是单一话题。

## 2. 内容平台负担最小化

- 内容平台选择的首要标准不是短期数据，而是是否减少维护负担、保护学习和探索时间。
- 理想平台应作为低摩擦放大器，让好内容长期发酵，而不是持续索取运营精力。
- 如果某平台获取流量的维护成本过高，应降格为“发完就走”的分发触点。

## 3. 内容指标观

- “轻互动”指点赞、赞同等低成本反馈，更接近读者“怎么说”。
- “强行为”指收藏、分享、长期搜索流量等需要更高意愿或带来长期访问的行为，更接近读者“怎么做”。
- 深度内容更应重视强行为和长尾价值，不被表层热度绑架。
